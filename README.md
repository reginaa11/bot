#  VK Language Bot

Чат-бот для ВКонтакте, который помогает работать с русским языком: подбирает синонимы, объясняет значения слов, находит рифмы и показывает примеры использования.

## Функционал

| Команда | Описание | Тип |
|---------|----------|-----|
|  Синоним | Поиск синонимов к слову | **Парсинг HTML** |
|  Толкование | Объяснение значения слова | **HTTP API** |
|  Рифма | Подбор рифм | **HTTP API** |
|  Пример | Примеры использования | **HTTP API** |

## Управление

- Клавиатура с кнопками для быстрых команд
- Можно просто написать слово — бот предложит варианты

## Технологии

- Python 3.9+
- vk_api — работа с API ВКонтакте
- BeautifulSoup4 — парсинг HTML (синонимы)
- requests — HTTP-запросы к API
